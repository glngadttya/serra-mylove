# serra-mylove 💌

Surat maaf virtual untuk cewek tercinta — **satu file HTML** (Tailwind CSS CDN + Font Awesome 6, tanpa build step, tanpa dependency lain).

**Cara buka:** klik `index.html`, atau buka langsung di browser.
**Live:** https://glngadttya.github.io/serra-mylove/

## Alurnya
1. **Sambutan** — Poco (karakter cewek kartun) menyapa, ada bubble yang ngomong sendiri.
2. **Tantangan 1 — Tangkap Hati** 🎮 geser keranjang, tangkap 10 hati jatuh.
3. **Tantangan 2 — Pecah Balon Huruf** 🎈 pecah balon sesuai urutan sampai membentuk `TERIMA KASIH`.
4. **Tantangan 3 — Stop the Love Meter** 💗 klik saat penanda di area pink, 3 kali berturut-turut.
5. **Kotak Rahasia** 📦 (bisa digoyang) → terbuka, keluar cahaya + confetti.
6. **Surat** ✉️ efek typewriter, ekspresi karakter berubah per paragraf, 3 polaroid foto, tombol Peluk/Cium/Hujan, Love Meter.
7. **Balasan + Finale** 💌 isi balasan → layar penuh hujan hati + bisa di-*print* suratnya.

## Fitur
- Karakter SVG satu file dengan 4 ekspresi (happy / joy / shy / kaget) + blink, ayunan lengan, odango goyang.
- 3 mini-game beneran (bukan cuma teks), ada HUD, lives, level, dan tombol lewati.
- Audio Web Audio API (musik lullaby + SFX), bisa dimatiin.
- Semua ikon pakai Font Awesome (nggak ada emoji bawaan).
- 100% responsif, jalan di HP.

Settings → Pages → Source: `main` / `/ (root)` → Save.
