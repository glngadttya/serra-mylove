# serra-mylove 💌

Surat maaf virtual untuk cewek tercinta — **satu file HTML** (Tailwind CSS via CDN, tanpa build step).

**Cara buka:** klik `index.html`, atau buka di browser langsung.

## Isi
- 🎀 Halaman pembuka + gate "tiket masuk"
- 🎮 Mini-game: tangkap 5 hati jatuh buat dapat kunci
- 📦 Kotak surat secret yang bisa digoyang & dibuka (confetti + light burst)
- 💌 Surat dengan efek typewriter + karakter kartun SVG yang ngomong
- 💖 Love meter, tombol Peluk/Cium/Hujan, musik lullaby (Web Audio API)
- 📝 Kotak balasan + finale + bisa di-*print* suratnya

## Cara host (GitHub Pages)
Settings → Pages → Source: `main` / `/ (root)` → Save.
